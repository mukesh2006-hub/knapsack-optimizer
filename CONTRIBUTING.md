# Contributing to Knapsack Optimizer

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/knapsack-optimizer.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes: `npm run dev`
6. Commit: `git commit -m "Add: your feature description"`
7. Push: `git push origin feature/your-feature-name`
8. Create a Pull Request

## Code Style

- Use TypeScript for type safety
- Follow existing code patterns
- Run `npm run format` before committing
- Run `npm run lint` to check for issues

## Commit Messages

Use clear, descriptive commit messages:
- `Add: new feature description`
- `Fix: bug description`
- `Refactor: code improvement description`
- `Docs: documentation update`

## Testing

Before submitting:
1. Run `npm run dev` and test manually
2. Check for console errors
3. Verify on multiple screen sizes

## Questions?

Open an issue to discuss before starting major work.

Thanks for contributing! 🙏
